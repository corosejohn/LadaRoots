# LadaRoots 🌶️

LadaRoots is an AI-powered mobile app that helps Malaysian pepper farmers manage their harvest, track stock, and connect with buyers.

## Features
- **AI Chat:** Record harvests using text, voice, or photos.
- **Inventory:** Track pepper stock and harvest records.
- **Sales Listings:** List pepper for sale.
- **Buyer Offers:** Receive and manage offers from buyers.
- **Demand Requests:** View buyer demand and plan future harvests.
- **Market Prices:** Refer to Malaysian Pepper Board (MPB) prices.

## Tech Stack
- React Native & Expo
- TypeScript
- Supabase
- AI Integration

## Getting Started

```bash
git clone <YOUR_REPOSITORY_URL>
cd ladaroots
npm install
npx expo start
```

## Project Goal

To help Malaysian pepper farmers manage their harvests more easily and sell their pepper more efficiently.
